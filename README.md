# ESRGAN Module

ESRGAN module with IREE.gd, packaged with Brisklance.

## Directories Descriptions

Here discusses the crucial directory.

| Directory                         | Description                                                                                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `res://addons/brisklance/self/assets` | Here lies all the assets that supports the example.                                                                                                  |
| `res://addons/brisklance/self/bytecode` | Here lies all the `.vmfb` bytecodes of ESRGAN module.                                                                                                  |
| `res://addons/brisklance/self/resources` | Here lies all the resources that supports the example.                                                                                                  |
| `res://addons/brisklance/self/example` | Here lies the example that shows the usage of `.vmfb`.                                                                                                  |
